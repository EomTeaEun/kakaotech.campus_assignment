- AI 활용 내용 :  한 주 전체의 todo 를 한눈에 볼 수 있고, 각 날짜에 어떤 todo 가 있는지 확인 할 수 있다. 주간 뷰에서 아이템 클릭 시 currentViewDate를 해당 todo의 날짜로 변경시키고, 패널을 일간 뷰로 자동 전환 한 뒤 날짜 네비게이터 + 인벤토리 슬롯도 함께 바뀌며 해당 날짜로 이동되게 만들었다.

## 구현하면서 고민한 점
구현 과정에서 막혔던 부분이나 고민했던 내용, 해결 방법을 자유롭게 작성해요.

- 고민한 점 : 일반적인 todo 앱을 만드는게 좀 더 편할 것 같긴 했지만 개발을 재밌게 하고 싶어서 todo 앱의 컨셉을 좀 많이 고민했던 것 같다.

- 막힌 점 :
	 1. 프론트엔드를 아직 잘 몰라서 그런지 UI 구성을 할 때 조금 힘들었다. 픽셀을 하나하나 재면서 배치하는게 맞나? 라는 생각이 들었다. ppt 를 만들 때 처럼 오브젝트를 배치할 때 간단하지 않았어서 힘들었다.
	 2. 중간에 구현 요구사항을 몇개 빼먹어서 변수, 코드 구조를 수정하였었다.
	 3. 이전 날짜는 마감기한으로 설정하지 못하도록 막기, 마감기한을 따로 수정하지 않으면 그 당일까지 마감기한으로 설정 되도록 하기 등등 내가 직접 사용해봐야 알 수 있는 오류 발생 지점을 찾는게 힘들었다.
	 4. 전체적인 흐름에 새로운 기능을 추가할 때 마다 어디에 어떻게 버튼을 추가해야하고, 어떤식으로 만들어야 사용할 때 흐름이 자연스러운지 고민을 많이 하였다.

- 해결 방법 : 
	1. 근본적인 문제는 해결하지 못하고 값을 수정하면서 배치하였다.
	2. 구현해야 할 사항을 정리 해두었다.
